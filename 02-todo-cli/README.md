# 📋 Todo CLI

A simple command-line Todo application built with Python.

---

## 📂 Project Structure

```text
02-todo-cli/
├── main.py
├── todo.py
├── requirements.txt
├── README.md
└── todo.json
```

---

## ⭐ Features

- Add tasks
- View all tasks
- Complete tasks
- Delete tasks
- Input validation
- Handles invalid JSON and missing `todo.json`

---

## 🚀 How to run?

1. Create a virtual environment

```bash
python -m venv venv
```

2. Activate the virtual environment

Windows
```bash
venv\Scripts\activate
```

macOS/Linux
```bash
source venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
python main.py
```

--- 

## 🛠️ Commands

| Command | Description |
|---|---|
| `/add` | Add a new task |
| `/view` | View all tasks |
| `/complete` | Mark a task as completed |
| `/delete` | Delete a task |
| `/help` | Show available commands |
| `/exit` | Exit the application |
