# 📋 Todo CLI

A simple command-line Todo application built with Python.

---

## 📂 Project Structure

```text
02-todo-cli/
├── main.py
├── tasks.json
├── sample.json
└── README.md
```

---

## ⭐ Features

- Add tasks
- View all tasks
- Complete tasks
- Delete tasks
- Input validation
- Handles invalid JSON and missing `tasks.json`

---

## 🚀 How to run?

Copy code and run using:

```bash
python main.py
```

--- 

## 🛠️ Commands

| Command | Description |
|---|---|
| `/add` | Add a new task |
| `/view` | View all tasks |
| `/complete [id]` | Mark a task as completed |
| `/delete [id]` | Delete a task |
| `/menu` | Show available commands |
| `/exit` | Exit the application |
