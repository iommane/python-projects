# 🎮 Number Guessing Game

A beginner Python project where the computer generates a random number and the player tries to guess it.

---

## ⭐ Features

- Difficulty levels
- Attempt counter
- Max attempts
- Validate inputs
- Hints

---

## 🚀 How to run?

Run command:
```bash
python main.py
```
