# 📊 Expense Tracker

A simple command-line Expense Tracker built with Python.

---

## 📂 Project Structure

```text
03-expense-tracker/
├── main.py
├── records.json
├── sample.json
└── README.md
```

---

## ⭐ Features

- Add expense
- View all expenses
- Delete expenses
- Show expense summary
- Input validation
- Handles invalid JSON and missing `records.json`

---

## 🚀 How to run?

Copy code and run using:

```bash
python main.py
```

--- 

## 🛠️ Commands

| Command | Description |
|---|---|
| `/add` | Add a new expense |
| `/view` | View all expenses |
| `/delete` | Delete a expense |
| `/summary` | Show expense summary |
| `/menu` | Show available commands |
| `/exit` | Exit the program |
